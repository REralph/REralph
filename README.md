# Hi, I'm Ralph 👋

I build practical software for problems I run into myself: a phone and PC organiser app that syncs over
encrypted Wi-Fi, computer-vision automation for video editing, YouTube channel tooling on Google's APIs, and a
Firefox extension that helps me stay focused while studying. I care about software that is reliable, tested and
clearly documented.

🎯 **Looking for an entry-level role in IT support or software development in the UK.**

## Featured projects

| Project | What it does | Built with |
|---|---|---|
| **[Mimi desktop](https://github.com/REralph/mimi-desktop)** | Windows companion to my Android organiser app: calendar, habits, tasks, gym log and a Gmail job-application tracker, synced from the phone over encrypted Wi-Fi. 833 automated tests. **[Try the demo](https://github.com/REralph/mimi-desktop/releases/latest)** | Kotlin · Compose Desktop · Gmail API · OAuth 2.0 |
| **[BF5 Auto Marker](https://github.com/REralph/bf5-auto-marker)** | Finds every kill in Battlefield V gameplay with computer vision and drops markers on the DaVinci Resolve timeline automatically. 197 tests. | Python · OpenCV · CustomTkinter · Resolve API |
| **[YT Schedule Manager](https://github.com/REralph/yt-schedule-manager)** | Uploads and schedules YouTube Shorts, checks each upload arrived, keeps the queue in order and can boost the schedule automatically each day. | Python · YouTube Data API v3 · OAuth 2.0 |
| **[Study Mode](https://github.com/REralph/study-mode)** | Firefox extension that blocks TikTok, Instagram and other distracting sites while you study, with exceptions for coursework and a password lock. Tested in a real headless Firefox. | JavaScript · Node · Python |
| **[YouTube Player Tweaks](https://github.com/REralph/youtube-player-tweaks)** | Firefox extension that restyles the YouTube player and adds a Comments side panel in cinema mode. | JavaScript · CSS |

Every project has a download on its **Releases** page, with screenshots and setup steps in its README.
